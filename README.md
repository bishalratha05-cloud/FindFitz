# 🔍 FindFitz – Web Search Mining System

FindFitz is a Flask-based document search and retrieval system designed to make searching, indexing, and managing documents easier and faster.

## 🚀 Features

- Document upload and management
- Automatic document indexing
- Full-text search
- TF-IDF-based search ranking
- Stemming and text processing
- Search result highlighting
- Relevant text snippets
- Document preview
- Search history
- Pagination of search results
- Inverted index support

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Information Retrieval
- Natural Language Processing
