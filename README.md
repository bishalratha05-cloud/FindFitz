# 🔍 FindFitz – Web Search Mining System

FindFitz is a Flask-based document search and retrieval system designed to make searching, indexing, and managing documents easier and faster.

## 🚀 Features

- Document upload and management
- Automatic document indexing
- Full-text search
- TF-IDF-based search ranking
- Stemming and text processing
- Search result highlighting
- Relevant text snippets
- Document preview
- Search history
- Pagination of search results
- Inverted index support

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- Information Retrieval
- Natural Language Processing

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/bishalratha05-cloud/FindFitz.git
```

### 2. Enter the project directory

```bash
cd FindFitz
```

### 3. Create virtual environment

```bash
python -m venv .venv
```

### 4. Activate virtual environment

Windows:

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open in browser

http://localhost:8000
